# IMO 纸三角形剪切博弈（单于 vs 木兰）交互教学系统文档

本文档详细介绍了基于国际数学奥林匹克（IMO）第 4 题制作的交互式启发教学网页的设计理念、数学证明原理、系统技术架构、单于必胜防守定理与动画演示引擎。

---

## 一、 题目背景与规则复述

### 1.1 题目规则
单于（Shan-Yu）和木兰（Mulan）在玩一个纸三角形剪切游戏。
- **初始已知条件**：双方已知一个角度 $\theta$ （满足 $0^\circ < \theta < 180^\circ$）。
- **初始状态**：单于制作一个任意形状和尺寸的纸质三角形 $T$。
- **游戏回合循环**：
  1. **胜负判定**：若 $T$ 中至少有一个内角恰好等于 $\theta$，游戏结束，木兰获胜！
  2. **木兰剪切**：若未出现 $\theta$ 角，木兰在 $T$ 的边界上选择一个不同于三个顶点的点 $P$，并沿着点 $P$ 到其对顶点的连线进行直线剪切，将 $T$ 剪成两个新三角形 $T_1$ 与 $T_2$。
  3. **单于选择**：单于弃置这两个三角形中的一个，剩下的另一个三角形成为新的 $T$。
- **核心问题**：对于哪些实数 $\theta$ 的值，无论单于如何应对，木兰都能保证在有限步内获得胜利？

## 💡 精辟几何发现：钝角对边高线破局法（单于 2 步必输）

### 1. 几何图示：从钝角顶点向最长对边引高线

```
                A (钝角 A > 90°)
               /|\
              / | \  (高线 AP 垂直于最长对边 BC)
             /  |  \ (垂足 P 必然落在对边线段 BC 内部！)
            /   |   \
           B----P----C
       (∠APB = 90°, ∠APC = 90°)
```

1. **垂足内落定理**：
   在钝角三角形 $ABC$ 中，钝角 $A$ 的对边 $BC$ 是最长边。从钝角顶点 $A$ 向对边 $BC$ 引高线 $AP$，**垂足 $P$ 必然精准落在对边线段 $BC$ 的内部**（绝不会落到延长线上）！

2. **双 90° 直角陷阱**：
   木兰沿着高线 $AP$ 剪切一刀，切口 $P$ 处的两个角 $\angle APB$ 和 $\angle APC$ **全部都是 $90^\circ$ 直角**！
   - 当 $\theta = 45^\circ$ 时，$90^\circ = 2\theta$ 危险倍数角！
   - 此时，左边 $\Delta APB$ 含有 $90^\circ = 2\theta$，右边 $\Delta APC$ 也含有 $90^\circ = 2\theta$！
   - **单于无论选择保留哪一边，手里的三角形都必然拿到一个 $90^\circ = 2\theta$ 直角！单于根本无法扔掉 $90^\circ$！**

3. **第二步绝杀**：
   单于拿到直角三角形后，木兰在第 2 步将这个 $90^\circ$ 直角从中间**平分为 $45^\circ + 45^\circ$（即 $\theta + \theta$）**。
   - 单于无论选留哪一边，手里的三角形都必含 $45^\circ = \theta \implies$ **单于第 2 步必败！**

## 二、 数学原理与深度讲解

### 2.1 结论
木兰能够保证在有限步内获胜的充要条件是：
$$ \theta = \frac{180^\circ}{n} \quad (n \ge 2, n \in \mathbb{Z}^+) $$

---

### 2.2 充分性证明（归纳递减锁杀链）
$$ k\theta \xrightarrow{\text{切出 } \theta} (k-1)\theta \xrightarrow{\text{切出 } \theta} (k-2)\theta \xrightarrow{\text{切出 } \theta} \dots \xrightarrow{} 2\theta \xrightarrow{\text{平分}} (\theta + \theta) $$
