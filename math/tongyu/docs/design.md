# 同余交互学习系统（Modulo Explorer）架构与设计规范

## 一、 系统概述

本项目是面向青少年及奥数学习者（小学高年级至初中奥赛水平）的**初等数论·同余互动学习系统**。系统以“直观探索引导 + 严谨逻辑论证 + 丰富例题实战”为核心理念，结合《数学奥林匹克小丛书·整除.同余与不定方程》与经典数论教材，构建 4 大篇章共 12 讲的现代化全景交互课件。

### 核心特色
1. **角色引导叙事**：姐姐（Sister，严谨导师）与妹妹（Younger，敏锐探索者）的启发式对话，生动展现认知冲突与顿悟过程。
2. **多模态内容块（Block-driven Architecture）**：
   - `dialogue`：对话推进块，支持逐句点击、角色头像、语音感气泡。
   - `story`：数学历史故事与生活隐喻背景卡片。
   - `concept`：四色认知概念盒子（绿色定理、蓝色易错、橙色比喻、灰色拓展）。
   - `canvas`：5 大专属 Canvas 交互实验台与模拟器。
   - `example`：启发式母题精讲块（含题目、思路启发、分步推演、通法提炼）。
   - `quiz`：交互式随堂测验与挑战题（含即时判定、详细错因分析）。
3. **完美数学公式渲染（KaTeX / MathType 渲染引擎）**：全套数论公式严格规范，排版优美，支持行内与独立公式的自适应渲染。

## 四、 5 大专属 Canvas 交互实验台设计

1. **`anim_modulo_clock` 动态模数时钟转盘**：
   - 包含钟表表盘、动态跳动指针与同余刻度高亮。
   - 用户可拖拽滑块切换模数 \\( m \\in [2, 24] \\)，输入任意整数 \\( a \\)，动画演示指针转圈并在 \\( a \\pmod m \\) 刻度精准定格。
2. **`anim_congruence_calc` 同余四则运算法则互动台**：
   - 动态调节两个操作数 \\( a, b \\) 及模数 \\( m \\)。
   - 视觉分流对比：通道 A 先求和/积后取模；通道 B 先各自取模后再求和/积并再次取模，展示余数等价性。
3. **`anim_power_orbit` 幂模轨道循环追踪器**：
   - 在圆形模环上绘制序列 \\( a^1, a^2, a^3, \\dots \\pmod m \\) 的跃迁轨道。
   - 动态标记循环节长度（周期 \\( T \\) 与阶 \\( d = \\text{ord}_m(a) \\)）。
4. **`anim_crt_gears` 中国剩余定理多齿轮啮合对齐仪**：
   - 显示模 3、模 5、模 7 的同心齿轮组。
   - 用户拖动全局数字指针，三组齿轮同步转动，当三个齿轮上的余数标记与目标 \\( (r_1, r_2, r_3) \\) 同时对齐时触发星光特效。
5. **`anim_residue_drawers` 剩余类抽屉与鸽巢分配器**：
   - 展示 \\( 0, 1, \\dots, m-1 \\) 共 \\( m \\) 个彩色抽屉。
   - 随机/自定义输入 \\( n \\) 个整数，动画演示各个数字依据 \\( x \\pmod m \\) 自动掉入对应的抽屉中，直观呈现抽屉原理。

## 五、 MathType / KaTeX 渲染标准与无损排版规范

1. **引入版本**：采用 KaTeX 0.16.9 最新生产版本，配备 `auto-render` 扩展。
2. **定界符标准**：
   - 行内公式：`\\( ... \\)`
   - 块级公式：`\\[ ... \\]`
3. **JavaScript 字符串安全转义**：
   - 包含数学公式的字符串使用单引号或模板字符串时，所有反斜杠必须写为双反斜杠 `\\`。
   - 包含撇号（导数/修饰符 `a'`）时统一用双引号 `"` 包裹外层字符串。
4. **公式 CSS 深度调优**：
   - `.katex` 字体大小适配主文本比例（`font-size: 1.08em`），文字基线垂直居中（`vertical-align: -0.05em`）。
   - 块级公式卡片带有优雅浅底色与左右内边距，公式溢出时支持横向平滑滚动。

## 六、 题库与质量保障机制

1. **题目数量**：12 讲每讲至少 3 道对话精讲母题 + 2 道随堂测验题，全系统包含至少 60 道完整例题。
2. **唯一全局 ID 体系**：
   - 母题 ID：`eg_1_1`, `eg_1_2`, `eg_2_1` ... `eg_12_3`
   - 测验题 ID：`q_1_1`, `q_1_2`, `q_2_1` ... `q_12_2`
3. **自动化测试**：
   - 配备全量数据脚本 Node 语法检验命令。
   - 公式转义检验与缺失 ID 校验脚本。
