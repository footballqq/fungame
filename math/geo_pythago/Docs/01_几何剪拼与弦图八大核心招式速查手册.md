## 一、3 秒看图决策树

1. **看到“剪成几块拼正方形”** → 先算总面积！
   - 总面积是完全平方数（如 25、36）→ 用**阶梯平移法**（9×4 → 6×6，长缩 3、宽增 2）。
   - 总面积不是完全平方数（如 41 = 4² + 5²）→ 用**勾股斜切法**（切两块 4-5 直角三角形平移）。
   - 要求“把大正方形分成 N 个小正方形” → 用**一分为四（+3 魔法）**，按 N 除以 3 的余数选底盘（1 块、6 块或 9 块）。
2. **看到“梯形 / 锯齿折线 / 60°角 / 折纸 / 连环直角”** → **造直角 + 整体平方**！
   - 梯形作高、折线横竖拉平、60° 角作高出 30°（对边 = 斜边一半）。
   - 连环直角一路只算平方不急开方；求面积设而不求盯住 x²；折纸用平方差 (a+b)(a-b)。
3. **看到“斜正方形 / 内部四角四边形 / 90°等腰 / 凹直角”** → 直接调用**弦图五大辅助线心法**！

## 二、重点抽象：弦图五大核心辅助线心法

| 招式名称 | 典型图形特征（何时出手） | 辅助线怎么画（核心动作） | 对应真题 |
| :--- | :--- | :--- | :--- |
| **① 认模型（内外弦图）** | 4 个全等直角三角形（或 4 个相同长方形）围成大小正方形 | 内弦图：大边 = c，小边 = b - a；外弦图：大边 = a + b，内边 = c | 例 10、例 11、练 10、练 11 |
| **② 穿外衣（外框补全法）** | 斜放的正方形、长方形内斜嵌 6/8 个正方形、以梯形腰作正方形、双直角五边形 | **横平竖直画外接大框**，四周立刻蹦出全等直角三角形（边 a、b），单个斜正方形面积 = a² + b² | 例 12、例 15、练 12、练 13、附加题 5 |
| **③ 画十字（内线伪弦图）** | 正方形/长方形内部斜躺一个不对称四角四边形（仅知对边线段和） | **过四顶点向内画横竖十字线**，四角一分为二，S阴 = (S总 + S中间小长方形) ÷ 2 | 例 13、例 14、练 14 |
| **④ 旋四份（4 倍补全法）** | 只给弦图的“四分之一”：AB=AD 且 AB⊥AD，或四直角凹多边形且 AE=CF | **复制 4 份绕顶点/中心旋转**拼成完整大外弦图，面积 = (S大 - S小) ÷ 4 | 附加题 2、附加题 4 |
| **⑤ 延一倍（风车与中点）** | 直角边向外延长一倍、正方形四边中点连线、四角剪 45° | **补全四条对称延长线**，构造“数学风车”或“5 等分中点弦图” | 练 9、练 15、练 16、附加题 3 |
