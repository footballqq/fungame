# 4×4 网格折纸厚度探秘 (Fold & Thickness) - 美工设计规范 (DESIGN.md)

本文档面向后续 UI 迭代与美工维护人员，规定了本游戏在视觉配色、纸艺质感、3D 透视物理动力学与声学动效的设计标准。

---

## 一、设计哲学：温润纸艺与拟物空间感

本游戏的设计语言定位于**“温润纸艺、格调数学、沉浸触感”**：
1. **纸张质感**：摒弃生硬的纯白与刺眼的黑框，采用暖调象牙白（`#fdfbf7`）、柔和羊皮纸灰（`#eae4d8`）与细致虚线折痕，营造真实的纸片触感；
2. **空间层叠**：通过 3D 透视转换与 CSS 3D Box-Shadow 深度映射，将“厚度”具象化为肉眼可见的高耸纸层；
3. **极客与和风**：兼顾传统折纸与几何数论，提供 4 组对比鲜明的纸艺皮肤。

### 4. 彩虹色谱皮肤 (Rainbow 16-Square Spectrum)
- 16 个小正方形根据初始序号分配 360° 均匀色环：
  $$\text{Hue} = ((id - 1) \times 22.5^\circ) \bmod 360^\circ$$
- 饱和度 80%，明度 65%，反面统一使用深板岩灰 `#37474f`，便于在多次翻折后清晰追踪每一个原始方格的最终归宿。

## 三、3D 空间动力学与透视规范

### 1. 视角转换参数
```css
.paper-board-container.perspective-3d {
    transform: perspective(900px) rotateX(42deg) rotateZ(-18deg) scale(0.9);
}
```
- **X 轴倾角**：42°（呈现最佳俯斜角，既看清顶面编号，又看清侧立面层叠厚度）；
- **Z 轴自旋**：-18°（营造黄金分割构图视角）；
- **视距**：900px（保持平缓自然透视，避免近大远小过度畸变）。

### 2. 堆叠厚度与阴影公式
每个单元格根据其包含的重叠层数 $K$，动态计算空间抬升高度与阴影投射：
- **物理高度**：$Z_{\text{depth}} = \min(K \times 3\text{px}, 40\text{px})$
- **阴影扩散**：$\text{box-shadow}: 0 \ (Z \times 0.8\text{px}) \ (Z \times 1.5\text{px}) \ \text{rgba}(0,0,0,0.35)$
- 随着层数增加（例如达到 8 层、16 层），方格明显高出周围基底，形成立体厚度对比。

## 四、数学公式排版规范 (MathType Standard)

严禁在页面中遗留裸露的 LaTeX 代码，所有公式必须遵循 MathType 级排版标准：
1. **公式专用字体**：
   `font-family: "Cambria Math", "Latin Modern Math", "STIX Two Math", "Georgia", serif;`
2. **变量规范**：所有数学单字母变量（$x, y, T_x, T_y, S_1, S_2$）必须使用 `<em>` 斜体渲染；
3. **下标规范**：下角标必须使用 `<sub>` 标签，字号设定为 `0.75em`，基线对齐下沉；
4. **运算符号**：乘法严格使用标准印刷乘号 `×`（U+00D7），禁止使用字母 `x` 或星号 `*`；不等式严格使用标准小于等于号 `≤`（U+2264）；
5. **展台卡片**：独立公式必须包装于 `.math-formula` 卡片中，具备学术浅金背景（`#fff8e1`）与微金边框（`#ffe082`）。
