# 因式分解与线性代数前置 - 互动学习项目设计文档

## 1. 项目目标
- **核心目标**：让小朋友通过互动游戏迅速掌握因式分解的十种核心方法与进阶技巧，为后续学习高等线性代数（如矩阵分解、特征值）打下坚实的几何与代数直觉。
- **教学基调**：闯关游戏模式。弱化长篇剧情对话，强化目标导向的“试炼”与“解谜”。

## 2. 章节与关卡设计
基于《basicfactor.md》中的“执行逻辑树（按项数分类）”，将 10 种基础方法与进阶技巧融入以下关卡：

### 关卡 0：项数雷达站（预备）
- **核心玩法**：项数扫描仪。玩家需要在限定时间内，快速判断掉落的多项式是几项，并送入对应的轨道。
- **涵盖技能**：提取公因式（所有因式分解的最高优先级 Step 1）。

### 关卡 1：两项式之岛
- **核心玩法**：天平与镜像。
- **涵盖技能**：平方差公式、立方和与立方差公式（SOAP 密码破解）。如果遇到平方和，直接亮起“无法分解”红灯（数域限制初体验）。

### 关卡 2：三项式之森
- **核心玩法**：代数拼图（Algebra Tiles）与十字相乘密码锁。
- **涵盖技能**：
  1. 完全平方公式（拼成完美正方形）。
  2. 首项系数为1的二次三项式（寻找和与积）。
  3. 首项系数不为1的二次三项式（十字相乘密码锁破解）。

### 关卡 3：多项式迷宫（四项及以上）
- **核心玩法**：连连看与空间折叠。
- **涵盖技能**：分组分解法、添项与拆项法（无中生有构造完全平方式）。

### 关卡 4：降维打击工厂（高阶）
- **核心玩法**：多项式除法机器。
- **涵盖技能**：换元法、长除法、综合除法（流水线作业，输入猜测的根，观察降维后的商）。

### 关卡 5：绝对领域（深渊模式）
- **核心玩法**：逻辑审判。
- **涵盖技能**：艾森斯坦判别法。识别“不可约”的陷阱题，避免死循环。

## 3. 核心互动组件 (Canvas / React Components)

### 3.1 代数拼图 (Algebra Tiles)
- **视觉**：大正方形 ($x^2$)，长方形 ($x$)，小正方形 ($1$)。可自由拖拽。
- **交互**：玩家需要将散落的方块拼成一个完美的无缝矩形。拼接成功后，系统的长和宽自动转化为两个因式（如 $(x+1)(x+2)$）。

### 3.2 十字相乘密码锁 (Cross-Multiplication Lock)
- **视觉**：一个 2x2 的矩阵密码锁，外加一个校验器。
- **交互**：玩家上下拨动两列数字（分别对应首项和常数项的因子）。转动时，中心会对角线相乘并相加，如果结果匹配中间项，门锁变为绿色打开。

### 3.3 多项式除法机器 (Polynomial Divider)
- **视觉**：带有漏斗和传送带的蒸汽朋克机器。
- **交互**：丢入多项式后，机器卡壳。玩家需要通过旋钮输入一个测试根（如 $x=2$）。输入正确时，机器运转，传送带送出降维后的商多项式。

### 3.4 项数扫描仪 (Term Scanner)
- **视觉**：雷达扫描 UI。
- **交互**：多项式飞过屏幕，玩家需要在 1 秒内点击“2项”、“3项”或“多项”按钮，选错会损失 HP。

## 4. 工程与技术栈
- **框架**：Vite + React (TypeScript 可选，优先 Vanilla JS 风格以降低复杂度)。
- **样式**：Vanilla CSS，沿用微积分项目中的深色宇宙风（Dark Theme），主色调可改为代表代数的紫色/橙色（区别于微积分的蓝色）。
- **状态管理**：复用或重构微积分项目中的 `Store` 逻辑，管理玩家的 XP、关卡解锁状态和成就（如“十字相乘大师”、“艾森斯坦审判官”）。
- **数学公式**：集成 KaTeX 进行多项式的动态渲染。

## 5. 开发路线图 (Roadmap)
1. **阶段 1**：Vite+React 环境搭建，CSS 基础设计系统移植，配置 KaTeX。
2. **阶段 2**：开发核心互动组件（优先开发代数拼图和十字密码锁）。
3. **阶段 3**：组装关卡框架，实现关卡路由与状态存档。
4. **阶段 4**：录入所有关卡的剧本数据与挑战题库。
