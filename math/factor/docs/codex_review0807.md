# 因式分解项目审查与补充计划（0807）

## 审查范围

- 基准内容：[basicfactor.md](./basicfactor.md)
- 教学数据：`src/data/chapter0.json` 至 `chapter5.json`
- 互动组件、出题器与题库数据

## 已覆盖内容

提取公因式、平方差、立方和/差、两类二次三项式、完全平方、因式定理、综合除法与艾森斯坦判别法均已有对应课程内容；代数拼图、十字相乘锁、综合除法机器也已实现。

## 发现的缺口

1. 分组分解仅在出题器中出现，课程主线缺少完整讲解和练习。
2. 添项/拆项法、换元法、长除法没有完整的教学数据与测验。
3. 第 0 关设计中的“项数扫描仪”没有实现。
4. 多个知识点只有一题测验，不满足 PRD 中“每个知识点 2–3 题”的目标。
5. “PDF经典教材真题”实际内嵌在页面组件中，没有原始 PDF、来源、页码、题型和难度等可追溯信息。
6. 多变量复合、双十字、待定系数、对称多项式、数域差异等尚未完整进入课程数据与章节测验。

## 本次实施

- 新增项数扫描仪，训练按项数识别结构。
- 在第 3 关补充分组分解、添项拆项法与测验。
- 在第 4 关补充换元法、长除法与测验。
- 将“PDF经典教材真题”迁移至独立题库，并补齐 `source`、`page`、`method`、`difficulty` 元数据。
- 将多变量复合、双十字、待定系数、对称多项式、艾森斯坦与数域差异纳入正式课程与出题类别。
- 为每章增加综合试炼，作为该章通关前的独立考核。

## 后续建议

- 为每个核心方法继续补充多套参数化题目与分步解析。
- 在取得原始 PDF 及授权信息后，填写题库的真实书名、页码和题号；当前元数据仅标注为“待核验”。
- 进阶内容是天才培养主线的一部分，应继续扩展相应互动组件、章节综合试炼与终极考核题库。
