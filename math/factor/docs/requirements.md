# 因式分解与线性代数前置 - 详细需求规格说明书 (PRD)

## 1. 系统概述
本项目是一个基于 Vite + React + Vanilla CSS 构建的**单页交互式学习应用 (SPA)**，旨在通过“闯关游戏”的形式，详细地向中小学生教授因式分解的 10 种基础方法与 3 种进阶方法。该系统作为微积分项目的姊妹篇，采用相同的多用户进度追踪机制，但交互模式从“纯剧情对话”升级为“游戏化试炼”。

## 2. 核心功能需求

### 2.1 多用户与进度管理模块
* **本地存储**：使用浏览器的 `localStorage` 进行纯前端数据持久化。
* **用户管理**：
    * 支持创建多个用户角色（输入昵称、选择随机小头像）。
    * 支持在不同用户之间无缝切换。
    * 记录每个用户的最后登录时间、连续打卡天数（Streak）。
* **进度追踪**：
    * 每一关的解锁状态（Locked / Unlocked / Passed）。
    * 每个用户累积的经验值（XP），以金币或星星的形式展现。
    * 详细记录每道测验题的答题次数、正确率、最近一次作答结果。
    * 热力图（Heatmap）支持：在用户档案页展示学习活跃度。

### 2.2 闯关学习模块（核心）
* **知识点覆盖**：严格遵守 `basicfactor.md` 的内容，覆盖提公因式、分组分解、十字相乘、各类公式、长除法及综合除法等 10+ 种方法。
* **教学颗粒度（事无巨细）**：
    * 每一个概念必须配有前置引入。
    * 必须拆解思考路径（如：面对三项式，大脑应该做哪些判断？）。
    * 不仅教“怎么做”，还要解释“为什么这么做”（原理剖析）以及“特殊情况怎么处理”（不可约多项式的判定）。
* **教学展现形式**：
    * 交互式图文卡片渐进展开（控制信息流速度，防止大段文字枯燥）。
    * 关键步骤使用互动组件（如代数拼图拖拽、密码锁调节）让玩家亲自“动手”计算，而不是被动看动画。
* **测验机制 (Quizzes)**：
    * 每个知识点讲解后紧跟 2-3 道基础测验题（单选/多选/填空）。
    * 答错提供针对性解析，允许无限次重试，首次答对奖励 XP。
* **终极考核 (Boss Challenge)**：
    * 每章末尾设有“本章综合试炼”。
    * 整个因式分解星球通关后，设有一个终极 Boss 战（混合所有题型的计时挑战或连胜挑战）。只有通过考核才能获得通关徽章。

### 2.3 互动组件需求 (Interactive Widgets)
1. **代数拼图 (Algebra Tiles)**：
    * 渲染不同面积的矩形块：大蓝方块（$x^2$）、长绿条（$x$）、小黄块（$1$）以及对应的负数红色块。
    * 玩家可拖拽、旋转这些块，试图拼成一个无空隙的大矩形。
    * 实时计算并显示玩家拼出的图形边长，转化为因式。
2. **十字相乘密码锁 (Cross-Multiplication Lock)**：
    * 用于破解 $ax^2+bx+c$。
    * 提供四个上下滚轮（两两分组），玩家拨动选择 $a$ 和 $c$ 的因数。
    * 中间实时显示交叉相乘求和的结果。若等于 $b$，锁变为绿色并弹开。
3. **多项式除法机器 (Polynomial Divider)**：
    * 用户输入猜测的“根”（例如输入 $2$）。
    * 机器流水线动画展示“综合除法”的下落、相乘、相加全过程。
    * 最终输出余数。若余数为 0，输出降次后的商。
4. **项数扫描仪 (Term Scanner)**：
    * 动态飞入各种多项式，玩家点击分类（2项、3项、4项）。

## 3. 非功能性需求
* **性能**：SPA 切换页面必须做到无缝无刷新，组件渲染延迟低于 100ms。
* **数学公式渲染**：集成 KaTeX，确保所有多项式排版专业、美观。
* **样式规范**：严格使用 Vanilla CSS Variables（不使用 Tailwind），沿用科幻宇宙、赛博朋克的暗色调 UI 风格，确保与数学星球体系视觉统一。
