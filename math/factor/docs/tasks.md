# 因式分解项目 - 开发任务拆解树 (Task Plan)

## Phase 1: 基础设施构建 (Infrastructure) - [ ] 未完成
* **Task 1.1**: 清理 Vite 默认模版代码，构建标准目录结构 (`src/components`, `src/pages`, `src/store`, `src/data`, `src/styles`)。
* **Task 2.2**: 建立全局 CSS 设计系统 (`variables.css`, `base.css`)，引入宇宙暗黑主题与主色调。
* **Task 1.3**: 搭建前端状态管理中枢 (`store/userStore.ts` 或 `.js`)，实现基于 `localStorage` 的多用户创建、切换、进度持久化读取与写入，以及打卡/经验值记录。
* **Task 1.4**: 配置基于 React Router 的页面路由（主页、用户页、章节页、考核页）。
* **Task 1.5**: 引入 KaTeX 依赖并在 React 中封装一个 `<MathText />` 组件，用于全局安全渲染多项式。

## Phase 2: 核心组件开发 (Core Components) - [ ] 未完成
* **Task 2.1**: 开发 `Layout` 和 `Navbar`（显示当前用户、经验值、返回学习地图等）。
* **Task 2.2**: 开发 `ContentBlock` 系列组件（替代原项目的 Vanilla JS 渲染）。
  * 渐进式显示控制器（点“继续”出现下一块）。
  * 知识卡片（ConceptCard，四色分级：提示、警告、定义、拓展）。
  * 嵌入式测验卡片（QuizCard，支持单选/多选，答错显示解释，答对奖励金币触发全屏撒花）。
* **Task 2.3 - Canvas 交互组件**：
  * 开发 `<AlgebraTiles />`（代数拼图拖拽引擎）。
  * 开发 `<CrossLock />`（十字相乘密码锁滚轮交互）。
  * 开发 `<DivisionMachine />`（除法机器流水线动画）。

## Phase 3: 教学内容编排与录入 (Content Generation) - [ ] 未完成
* **Task 3.0**: 编写数据结构方案，设计 JSON/JS 对象以存储每章的剧本与题库。
* **Task 3.1**: 录入【第0章：预备知识与提公因式】（讲透核心逻辑树的优先级，项数扫描仪体验）。
* **Task 3.2**: 录入【第1章：两项式的秘密】（平方差、立方和/差，不可约判定）。
* **Task 3.3**: 录入【第2章：三项式与十字相乘】（完全平方、十字相乘法详解与密码锁训练）。
* **Task 3.4**: 录入【第3章：多项式的变形】（分组分解、添项拆项，空间折叠动画）。
* **Task 3.5**: 录入【第4章：高阶降维打击】（换元法、长除法、综合除法）。
* **Task 3.6**: 录入【第5章：绝对领域】（艾森斯坦判别法、特殊技巧实战）。

## Phase 4: 考核与总结系统 (Exam & Profile) - [ ] 未完成
* **Task 4.1**: 建立大题库中心 (`data/quizzes.js`)，按难度和标签分类。
* **Task 4.2**: 开发章末考核页面 (`ExamPage.jsx`)，支持从题库中随机抽取 10 题组成试卷，带有倒计时与进度条。
* **Task 4.3**: 开发考核结算界面（打分、评星级、错题解析对照展示）。
* **Task 4.4**: 完善学习档案页 (`ProfilePage.jsx`)，展示雷达图、各项能力成就徽章、学习热力图。

## Phase 5: 测试与联调 (Testing & Review) - [ ] 未完成
* **Task 5.1**: 清除全站模拟数据，进行完整的“新用户首次注册 -> 学习全章 -> 考试通关”流程闭环测试。
* **Task 5.2**: 检查所有 KaTeX 渲染是否正常（特别是带有素数和高次幂的地方）。
* **Task 5.3**: 修正界面在较小屏幕上的滚动和响应式布局问题。
