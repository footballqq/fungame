⚡ 4 条完全平方数速算秘籍（背表快 3 倍）

  • 尾数 5 秒杀法：a5² = a×(a+1) 后接 25。例：35² = (3×4)25 = 1225，85² = (8×9)25 = 7225！
  • 平方尾数配对规律：平方数个位只可能是 0, 1, 4, 5, 6, 9（绝不会出现 2, 3, 7, 8）；互补尾数平方个位相同（1与9→1，2与8→4，3与7→9，4与6→6）。
  • 50 附近速算法：(50 ± d)² = (25 ± d)×100 + d²。例：47² = (25-3)00 + 9 = 2209，53² = (25+3)00 + 9 = 2809！
  • 100 附近速算法：(100 - d)² = (100 - 2d)×100 + d²。例：97² = 9400 + 9 = 9409，96² = 9200 + 16 = 9216！
