# 滑冰棋 (Ice Sliding Chess) - HTML 桌游对战

根据《桌游滑冰棋》规则设计的高品质纯前端桌面对战游戏。支持**人机对战（简单/中等/困难三档难度）**与**本地同屏人人对战**，具备纯原生 Web Audio 音效系统、SVG 矢量冰霜拟物风格界面、悔棋/重做与实时操作指引。

---

## 📖 核心规则 (严格遵循官方规范)

1. **棋盘结构**：由 19 个正六边形底座拼成的大六角形棋盘（中心 1 个，向外扩展两圈：1 + 6 + 12 = 19）。
2. **初始配置**：双方各执 3 枚棋子（红方与蓝方），间隔摆放在最外圈的 6 个角/边缘顶点上。
3. **回合行动（严格顺序两步）**：
   - **第 ① 步 移动棋子**：选择己方一枚棋子，沿 6 个六边形直线方向之一滑行（Ice-sliding 机制），直到碰到底座边缘、或碰到其它棋子阻挡停下，**不能中途自愿刹车**。
   - **第 ② 步 搬移底座**：拿掉最外圈一个没有棋子停留的空底座，重新拼入棋盘。要求**新位置至少与现有的 2 个底座边相邻**（保证棋盘始终全连通且不会被随意无限拉长）。
4. **胜利条件**：当某位玩家行动结束后，己方的 3 枚棋子**全部彼此两两相邻（组成互相紧挨的铁三角/连通块）**，即判定获胜！

## 🎮 游戏特色

- **多种对战模式**：
  - **人机对战（玩家执红·先手）**：与 AI 展开策略较量
  - **人机对战（玩家执蓝·后手）**：挑战 AI 先手布局
  - **人人对战（本地同屏双人）**：适合两人面对面对战
  - **AI 观战演示（AI vs AI）**：全自动策略推演展示
- **AI 智能等级**：
  - **简单**：随机探索与轻度距离贪心，适合新手教学
  - **中等**：一步绝杀判定、威胁防守与启发式距离/邻接评估
  - **困难**：深度 Minimax + Alpha-Beta 剪枝推演对手反制走法
- **纯原生 Web Audio API 音效系统**：
  - 纯数学公式合成冰刀划冰摩擦声、阻挡撞击声、底座上浮音、晶石卡入声与胜利大调琶音，无需加载任何外部 MP3/WAV 文件。
- **现代化视觉与交互**：
  - SVG 无损矢量图形，动态视口自适应居中。
  - 移动轨迹虚线指引、目标落点光环、最外圈底座呼吸金光高亮、新拼入位置候选点标识。
  - 支持直接点击目标底座或光环执行滑行，支持悔棋（Undo）与重做（Redo），支持六边形坐标显示切换。

## 🚀 启动与运行

### 方式 1：直接浏览器打开
直接在浏览器中打开 `index.html`（由于采用 ES Module，推荐现代浏览器如 Chrome / Edge / Firefox）。

### 方式 2：使用本地 HTTP 服务器（推荐）
在项目目录下执行：
```powershell
python -m http.server 8080
```
然后在浏览器中访问：`http://localhost:8080`

## 🧪 单元测试与验证

本项目采用测试驱动开发，涵盖 Python 与 Node.js 双重测试套件：

### 1. Python 规则引擎测试 (pytest)
```powershell
python -m pytest -v
```
测试覆盖：
- 六边形立方坐标系统与邻接几何计算
- 19 个底座初始化与连通性
- 冰面滑行（边界阻挡、棋子阻挡、禁止中途刹车）
- 底座移除连通性检验（割点判定、空底座约束）
- 新底座放置 $\ge 2$ 邻居约束
- 铁三角胜负判定
- AI 决策启发式评分与绝杀检测
- 前端静态文件完整性

### 2. JavaScript 前端核心逻辑测试 (Node.js)
```powershell
npm test
# 或执行
node tests/test_js_engine.js
```

### 3. AI vs AI 完整对局端到端自动模拟
```powershell
node tests/test_simulation.js
```
自动运行数十回合完整对弈，严格验证棋盘底座总数始终为 19、棋盘始终全连通、每枚棋子始终位于有效底座上，直到分出铁三角胜负。
