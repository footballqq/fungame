# 协作开发规范

本文件与根目录 `AGENTS.md` 保持一致，适用于本仓库（`fungame`）的日常协作开发：

- **语言与环境**：对用户输出始终使用中文，文件路径使用绝对路径；运行环境为 Windows PowerShell（`pwsh`）。
- **模块化设计**：HTML / CSS / JS 与 Python 校验模块按职责清晰拆分，避免代码重复与单文件过度膨胀（建议不超过 1500 行）。
- **教育游戏品质**：
  - 默认防剧透，让孩子先动手尝试，再结合分步启发式教学与严格数学解析。
  - 严禁残留原始 LaTeX 标记，统一使用语义 HTML 与标准数学符号排版。
  - 严禁使用原生 `alert()` / `confirm()`，统一使用内置弹窗与 Toast。
  - 兼顾桌面端、平板与手机触控自适应体验，保持离线零外链可用。
- **测试门禁**：所有改动需编写并通过对应 `pytest` 单元测试与 `node --check` 语法检查后再提交。
