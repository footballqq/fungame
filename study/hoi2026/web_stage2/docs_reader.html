第二赛段考纲与进阶学习方案

考纲依据

依据项目目录中的《海淀区信息学比赛考查内容参考.pdf》，第二赛段为计算思维挑战赛，采用集中笔试，时长 120 分钟。题型为单项选择（约 60%）和填空（约 40%）。考查范围如下：

范围具体内容
数学逻辑集合、函数、排列组合、逻辑命题判断
初等算法枚举、模拟、递归思想、简单贪心策略
数据结构数组、字符串、队列、栈的基本操作与特性
代码推理代码功能、运行结果、时间复杂度推算

本赛段强调计算思维，不等同于上机编程赛。PDF 所列第三赛段编程范围不应混入本阶段必考范围。

学习安排

  • 数学逻辑与离散基础：集合计数、函数映射、分类与分步、排列组合、命题真假。
  • 初等算法与简单贪心：枚举边界、模拟状态变化、贪心策略与反例。
  • 递归思维：递归出口、规模变化、调用与回溯；用小规模实例手推。
  • 数据结构：数组与字符串下标、栈后进先出、队列先进先出。
  • 代码分析与复杂度：逐行跟踪变量、循环次数计数、常见增长级别辨析。

每章依次进行概念教学、例题精讲、至少 5 道章节练习和错题复盘。完成章节学习后，再进行 120 分钟综合模拟。建议先限时独立作答，再逐题订正并记录错因。

第二赛段核心知识模块教学设计

本设计按 PDF 中第二赛段考纲组织。集合与计数、算法、递归、数据结构、代码分析分别在网站五个章节中练习；下列内容是概念讲授提纲，题目以网站题库为准。

1. 数学逻辑与离散基础

A ∪ B=A+B-A ∩ B
  • 函数要求定义域中的每个输入恰好对应一个输出；不同输入可以对应同一输出。
  • 加法原理用于互斥分类，乘法原理用于连续分步。排列考虑顺序，组合不考虑顺序。
  • 命题推理通过真值和条件逐项检查；“若 P 则 Q”的逆否命题为“若非 Q 则非 P”，两者等价。
  • 讲解时使用小集合、列表或树状图，要求学生说明分类互斥且覆盖完整。

2. 初等算法与简单贪心

  • 枚举须保证不重不漏；根据约束缩小范围时，要能说明被剪去的情况不可能成为答案。
  • 模拟先明确状态、初值、每一步规则和停止条件，再用表格跟踪状态。
  • 贪心每步做局部选择，但局部最优不自动保证全局最优。用反例检验策略，再讨论适用条件。
  • 区间调度的经典策略是按结束时间升序选择不冲突活动；这是特定问题的结论，不可推广成所有问题都选“最早”或“最短”。

3. 递归思维

正确递归要有明确的终止条件、朝终止条件推进的子问题，以及返回时如何组合答案。用 fact(n) = n * fact(n - 1) 且 fact(0) = 1 示范调用和回溯。斐波那契朴素递归会重复计算；汉诺塔移动次数满足 H(n) = 2H(n - 1) + 1，故 H(n) = 2ⁿ - 1。请限制示例规模，避免把递归误解成无限展开。

4. 数据结构与代码分析

  • 数组下标从 0 开始；长度为 n 的字符串非空连续子串数为 n(n+1)/2，子序列不要求连续。
  • 栈是后进先出，可用于括号匹配；队列是先进先出。循环队列需根据具体约定理解队头、队尾和空满判定。
  • 代码跟踪按语句记录变量，不跳步。复杂度描述输入规模增长趋势：单层 n 次循环通常为 O(n)，每次翻倍的循环通常为 O(log n)；嵌套循环需按真实执行次数分析。
  • 递归的额外空间通常与最大调用深度有关；运行时间和空间复杂度是不同问题。

教学闭环

每节按“先讲概念 - 手算例题 - 学生复述规则 - 至少 5 道独立练习 - 错题归因”进行。错因分为概念误解、边界遗漏、计算错误、代码跟踪跳步和策略未经证明。每章练习后安排限时小测，最后进行 120 分钟综合练习。

递归与初等算法专项练习指南

递归的三个检查点

  • 终止条件：最小子问题直接给出答案。
  • 递归推进：每次调用都向终止条件靠近。
  • 回溯合并：子问题返回后，当前层如何得到答案。

例如阶乘定义为 fact(0) = 1，fact(n) = n * fact(n - 1)（n > 0）。计算 fact(4) 时先到达 fact(0)，再依次返回 1、1、2、6、24。板书时分开画“调用下行”和“结果返回”，避免把两阶段混在一起。

常见递归模型

  • 线性递归：每层只调用一个规模更小的子问题，如阶乘。
  • 双分支递归：斐波那契朴素定义会重复计算同一项；不要笼统声称所有双分支递归都恰为 O(2ⁿ)，应结合递推式分析。
  • 汉诺塔：H(1) = 1，H(n) = 2H(n - 1) + 1，所以 H(n) = 2ⁿ - 1。
  • 递归与循环可表达相同计算过程，但递归调用会占用调用栈；最大递归深度决定相关额外空间。

初等算法解题步骤

枚举：列出变量范围，检查边界，确保每个候选恰好检查一次。能用约束缩短范围时，写明数学依据。

模拟：写清状态、初始值、转换规则和结束条件；用表格记录至少前几步，随后核对最终状态。

贪心：明确每一步的选择规则，用小例子和反例测试。仅在题目具有相应性质或能给出证明时采用。区间调度按结束时间升序选择是经典特例；零钱面额改变后，贪心可能失效。

课堂训练流程

每个模型先做小规模手算，再让学生独立画调用树或状态表，最后分析复杂度和边界。练习应覆盖：递归出口辨析、调用返回值、枚举范围、模拟过程和贪心反例。发现错误后指出错在终止条件、状态更新、候选遗漏或策略假设中的哪一项。
