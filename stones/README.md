# ♟️ 奇偶棋子谜题 (Parity Chess Puzzle)

本项目将国际象棋棋盘上的奇偶性数学奥数解答题（源自 `chessincube.jpg`）打造成了一款交互式 HTML5 网页益智解谜游戏。

---

## 📖 题目背景与数学问题

**原题描述**：
> 今有一个 6×6 的国际象棋棋盘，在其中放入一些棋子（每格最多放 1 枚），使得每行都有偶数（>0）枚棋子，每列都有奇数枚棋子，那么至少需要放入多少枚棋子？说明理由且给出构造方案。

### 📐 数学证明与结论

1. **下界推导（行约束）**：
   - 题目要求“每行都有偶数且大于 0 枚棋子”。
   - 大于 0 的最小正偶数是 2，因此每一行至少需要放入 2 枚棋子。
   - 棋盘共有 6 行，故棋子总数满足：
     $$\text{总棋子数 } S = \sum_{i=1}^6 r_i \ge 6 \times 2 = 12$$
2. **奇偶性相容（列约束）**：
   - 题目要求“每列都有奇数枚棋子”。
   - 棋盘共有 6 列，6 个正奇数的和必为偶数，与行和（6 个正偶数的和必为偶数）奇偶性完全一致。
3. **极小值构造方案（严格达到 12 枚）**：
   - 要让总棋子数等于 12 枚，每行必须恰好放入 2 枚棋子。
   - 列和必须为奇数，将 12 拆分为 6 个正奇数之和：
     $$12 = 3 + 3 + 3 + 1 + 1 + 1$$
     即前 3 列各有 3 枚棋子，后 3 列各有 1 枚棋子。
   - 显式构造矩阵：
     - 行 1: (列 1, 列 2) -> 行和 2
     - 行 2: (列 1, 列 3) -> 行和 2
     - 行 3: (列 2, 列 3) -> 行和 2
     - 行 4: (列 1, 列 4) -> 行和 2
     - 行 5: (列 2, 列 5) -> 行和 2
     - 行 6: (列 3, 列 6) -> 行和 2
   - 检验各列棋子数：
     - 列 1~3：各 3 枚（奇数）
     - 列 4~6：各 1 枚（奇数）
   - **结论**：至少需要放入 **12** 枚棋子，且上述构造方案成立。

## 🎮 游戏特色与功能

1. **经典木质国际象棋质感**：
   - 采用深浅交替的木纹棋盘格子，配以古典立体的雕花木质/象牙色质感棋子。
2. **实时奇偶反馈与指示**：
   - 棋盘顶端动态显示每列的棋子数、目标（奇）与对勾/错误徽章。
   - 棋盘右侧动态显示每行的棋子数、目标（偶）与对勾/错误徽章。
3. **多难度规格支持**：
   - **4×4 入门**：理论极小目标 8 枚。
   - **6×6 经典**：原题规格，理论极小目标 12 枚。
   - **8×8 大师**：理论极小目标 16 枚。
4. **解题辅助与智能提示**：
   - **撤销 / 重做**：方便多步尝试与回退。
   - **💡 智能提示**：根据当前盘面与数学解法，自动推荐下一步添加或移除棋子。
   - **✨ 演示官方最优解**：带逐步落子动画，直观呈现对称环形构造解。
   - **📖 查看数学原理解析**：弹窗展示严谨的分步证明步骤。
5. **视听盛宴**：
   - 使用 Web Audio API 合成拟真木质落子撞击声与胜利和弦。
   - 达成理论极小最优解时触发全屏彩屑烟花庆祝。

## 📁 文件结构

- `stones/index.html`：主游戏页面结构（<100行）
- `stones/style.css`：棋盘与界面木质象棋主题主样式（<500行）
- `stones/modal.css`：原理解析模态窗与提示样式（<120行）
- `stones/audio_fx.js`：Web Audio 音效合成与彩屑动画（<150行）
- `stones/solver.js`：前端核心算法库（校验、理论下界、构造与提示，<200行）
- `stones/board.js`：游戏状态机与 DOM 交互控制器（<360行）
- `stones/parity_math.py`：Python 版数学模型、理论验证与回溯求解器
- `tests/test_stones_parity_puzzle.py`：pytest 自动化单元测试用例
- `stones/solver.test.js`：Node.js 自动化单元测试用例
